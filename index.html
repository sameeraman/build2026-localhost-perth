About the Event

Built for developers and cloud engineers.

This in-person event is designed for developers and cloud engineers who want to design, build, and deploy real-world AI solutions on Azure. Expect a hands-on, implementation-focused experience using Microsoft Foundry and GitHub Copilot — with live demos and practical developer workflows you can take straight to your next project.


Whether you're shipping your first AI feature or scaling production systems, this event will give you actionable insights to accelerate your AI journey with Microsoft.
